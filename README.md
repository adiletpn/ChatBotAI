# DocMind AI — интеллектуальный чат-бот по документам

Проект для направления **AIChatBots** чемпионата «Innovation AI Hackathon – 2026» (п. 5.1.2 Ереже).

Пользователь загружает документы (PDF, DOCX, PPTX, XLSX, TXT, HTML, сканы и фото), задаёт вопрос
на **казахском, русском или английском** — бот отвечает строго по содержанию документов и показывает
**источник: файл и номер страницы** с цитатой. Доступен через **веб-интерфейс** и **Telegram**.

## 1. Что требует регламент и как это закрыто

| № | Требование (п. 5.1.2) | Как реализовано в DocMind AI |
|---|---|---|
| 1 | Работа с PDF, DOCX и другими документами | PDF, DOCX (вместе с таблицами), PPTX, XLSX, CSV, TXT, MD, HTML, DOC/RTF/ODT, JPG/PNG — [app/parsers.py](app/parsers.py) |
| 2 | Точные и понятные ответы по содержанию | RAG: поиск нужных фрагментов + LLM с жёстким промптом «только по документам», без выдумывания — [app/rag.py](app/rag.py) |
| 3 | ИИ и обработка естественного языка (NLP) | LLM, определение языка, стемминг для казахского/русского, BM25-поиск, перевод запроса на 3 языка |
| 4 | Telegram, WhatsApp или веб | Веб-платформа + Telegram-бот (оба сразу) |
| 5 | Рабочая версия | Запускается одной командой, есть автотест на 28 проверок [tests/smoke_test.py](tests/smoke_test.py) |
| 6 | Презентация + видео 5–7 мин | [docs/DocMind_AI_Presentation.pptx](docs/DocMind_AI_Presentation.pptx), сценарий видео [docs/VIDEO_SCRIPT.md](docs/VIDEO_SCRIPT.md) |
| 7★ | **Указание источника** (бонус) | Каждый ответ: ссылки [1], [2] → файл, страница/слайд/лист, цитата, кнопка «открыть документ на этой странице» |
| 7★ | **Многоязычность** (бонус) | Вопрос на любом из 3 языков к документу на любом из 3 языков; интерфейс ҚАЗ/РУС/ENG; голосовой ввод |
| 7★ | **Сканированные документы** (бонус) | OCR Tesseract (kaz+rus+eng) для сканов PDF, фото и картинок внутри DOCX; запасной вариант — vision-LLM |

### Чем DocMind отличается от «обычного чат-бота»

| Режим | Что делает |
|---|---|
| 📍 **Дәлел (доказательство)** | Клик по источнику открывает **настоящую страницу PDF**, где строки, на которых основан ответ, подсвечены жёлтым маркером. Под каждым ответом — индикатор доверия «подтверждено N источниками». |
| 🧭 **Карта документа** | Без единого вопроса AI раскладывает документ на хронологию сроков, ключевые цифры, интерактивный **чек-лист требований** и словарь терминов; у каждого пункта ссылка на страницу. |
| 🎓 **Проверка знаний** | Тест по документу (5/7/10 вопросов): варианты ответа, мгновенная проверка, объяснение со ссылкой на страницу, итоговый балл и разбор ошибок. Сценарий: работник прошёл инструктаж по охране труда — бот проверил, что он его усвоил. |

Все режимы работают и без LLM (упрощённо): карта — по регулярным выражениям (даты, числа с единицами, слова «тиіс / должен / must»), тест — «вставьте пропущенное число».

Критерии оценки (100 баллов): актуальность/уникальность идеи — 40, качество работы с документами и точность — 30,
функциональность — 15, презентация — 15. Поэтому основной упор сделан на **точность ответов с доказательством (источником)**
и на все три бонусные функции.

## 2. Как это работает (архитектура RAG)

```
 Документ ──► Парсер ──► (скан? → OCR) ──► Разбиение на фрагменты ──► Индекс BM25
                                                                         │
 Вопрос ──► Определение языка ──► Перевод запроса kk/ru/en (LLM) ──► Поиск фрагментов
                                                                         │
                         LLM: «ответь только по этим фрагментам, укажи [номер]»
                                                                         │
                         Ответ (стримингом) + источники: файл · страница · цитата
```

* **Парсинг** — PyMuPDF, python-docx, python-pptx, openpyxl, BeautifulSoup. Для каждого фрагмента
  запоминается «место»: страница PDF, слайд, лист Excel, раздел.
* **OCR** — если на странице PDF почти нет текста, она рендерится в картинку 300 dpi и распознаётся Tesseract
  с казахской, русской и английской моделями (лежат в папке `tessdata/`).
* **Поиск** — BM25 со стеммингом по префиксу: казахский язык агглютинативный (*чемпионат-қа, чемпионат-тың*),
  поэтому слова сводятся к основе. Короткие документы (< 14 000 символов) модель получает целиком.
* **Межъязыковой поиск** — LLM переписывает вопрос ключевыми словами на трёх языках: вопрос на русском найдёт
  ответ в казахском документе.
* **Генерация** — системный промпт запрещает выдумывать, требует отвечать на языке вопроса и ставить ссылки [n].
  Номера ссылок сопоставляются с фрагментами и показываются в интерфейсе.
* **Офлайн-режим** — без ключа API бот всё равно работает: показывает самые релевантные предложения
  с источниками (полезно, если на защите пропадёт интернет).
* **Диалог** — бот помнит последние 4 обмена репликами, понимает уточнения («а сколько баллов?»).
* **Изоляция** — у каждого браузера и каждого Telegram-чата свои документы.

## 3. Структура проекта

```
app/
  main.py          веб-сервер FastAPI, REST API, стриминг ответа (SSE)
  rag.py           ядро: поиск контекста, промпты, цитаты, резюме, офлайн-режим
  insights.py      карта документа, проверка знаний, подсветка доказательства на странице PDF
  llm.py           клиент LLM: OpenAI-совместимый и Anthropic-совместимый API, стриминг, vision-OCR
  parsers.py       извлечение текста из всех форматов
  ocr.py           распознавание сканов (Tesseract kaz+rus+eng)
  chunker.py       разбиение на фрагменты с перекрытием
  retriever.py     поиск BM25 + стемминг kk/ru/en
  store.py         хранилище документов (data/store.json)
  lang.py          определение языка, локализация
  telegram_bot.py  Telegram-бот (aiogram 3)
  config.py        настройки из .env
web/               веб-интерфейс (HTML/CSS/JS, без сборки)
samples/           демо-документы для показа
tessdata/          языковые модели OCR: kaz, rus, eng
tests/smoke_test.py  автотест (28 проверок)
docs/              презентация, сценарий видео, список ИИ-инструментов
```

## 4. Запуск

### macOS / Linux
```bash
./run.sh
```
### Windows
Двойной щелчок по `run.bat` (нужен установленный Python 3.10+).

Открыть **http://localhost:8000**. При первом запуске создаётся виртуальное окружение и файл `.env`.

OCR для сканов: macOS — `brew install tesseract`; Windows — установщик
[UB-Mannheim/tesseract](https://github.com/UB-Mannheim/tesseract/wiki) (и добавить в PATH).
Казахская и русская модели уже лежат в `tessdata/`.

### Проверка
```bash
.venv/bin/python tests/smoke_test.py
```

## 5. Подключение API (xKiro или любой другой)

Откройте файл `.env` и заполните 3–4 строки, затем перезапустите сервер.

**Если API OpenAI-совместимый** (большинство бесплатных прокси, в т.ч. kiro-прокси, OpenRouter, Groq):
```env
LLM_PROVIDER=openai
LLM_BASE_URL=https://<адрес-вашего-api>/v1
LLM_API_KEY=<ваш ключ>
LLM_MODEL=<имя модели, например claude-sonnet-4.5>
```
**Если API Anthropic-совместимый** (эндпоинт `/v1/messages`):
```env
LLM_PROVIDER=anthropic
LLM_BASE_URL=https://<адрес-вашего-api>/v1
LLM_API_KEY=<ваш ключ>
LLM_MODEL=<имя модели>
```
Как понять, какой протокол: если в документации сервиса есть `/v1/chat/completions` — это `openai`;
если `/v1/messages` — `anthropic`. В `LLM_BASE_URL` пишется адрес **до** `/chat/completions` (обычно оканчивается на `/v1`).

Проверка подключения: откройте http://localhost:8000/api/llm-check — должно быть `"ok": true`.
В левом нижнем углу интерфейса зелёная точка «AI-модель: …» означает, что модель подключена.

Если модель поддерживает изображения, можно включить `VISION_OCR=true` — тогда сканы будут распознаваться
моделью, даже если Tesseract не установлен.

## 6. Telegram-бот

1. В Telegram откройте **@BotFather** → `/newbot` → получите токен.
2. Впишите в `.env`: `TELEGRAM_BOT_TOKEN=123456:ABC...`
3. Перезапустите сервер — бот запустится вместе с ним.

Отправьте боту файл или фото документа, затем задавайте вопросы. Команды: `/docs`, `/summary`, `/clear`.

## 7. Как дать жюри доступ к рабочей версии

* **Telegram-бот** — работает, пока запущен ваш ноутбук, ссылка вида `t.me/<имя_бота>`.
* **Публичная ссылка на веб-версию** (бесплатно, без регистрации):
  ```bash
  brew install cloudflared
  cloudflared tunnel --url http://localhost:8000
  ```
  Появится адрес `https://....trycloudflare.com` — его можно отправить.
* **Постоянный хостинг** — Render.com / Railway: команда запуска
  `uvicorn app.main:app --host 0.0.0.0 --port $PORT`, переменные окружения — как в `.env`.
