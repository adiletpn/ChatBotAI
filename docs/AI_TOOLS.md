# Использованные ИИ-инструменты (п. 6.2 Ереже)

Регламент разрешает использовать ИИ при разработке, но требует указать инструменты и их роль.
Отредактируйте список так, чтобы он честно отражал вашу работу.

| Инструмент | Роль в проекте |
|---|---|
| Claude Code (Anthropic) | Помощь в написании и отладке кода, генерация демо-документов, черновик презентации и сценария видео |
| LLM через API (`LLM_MODEL` в `.env`, провайдер — ___) | Внутри продукта: формирование ответов по документам, перевод запроса на kk/ru/en, краткое содержание документа |
| Tesseract OCR (открытый движок, модели kaz/rus/eng) | Внутри продукта: распознавание сканированных документов и фотографий |

Работа команды: постановка задачи и анализ требований регламента, выбор архитектуры, тестирование на
своих документах, настройка и подключение API, подготовка демонстрации, презентации и защиты проекта.
