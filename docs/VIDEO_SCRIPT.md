# Сценарий видеоролика DocMind AI (≈ 6 минут, требование: 5–7 минут)

Запись экрана: QuickTime → «Новая запись экрана» (macOS) или OBS. Голос — за кадром.
Перед записью: подключите API в `.env`, перезапустите сервер, очистите чат, держите файлы из `samples/` под рукой.
Можно говорить на казахском или русском — оба языка рабочие (п. 4.6).

| Время | В кадре | Текст за кадром |
|---|---|---|
| 0:00–0:30 | Титульный слайд | «Здравствуйте! Мы команда ___ из ___. Наш проект для направления AIChatBots — DocMind AI: интеллектуальный чат-бот, который читает документы и отвечает на вопросы по ним на казахском, русском и английском, всегда показывая источник.» |
| 0:30–1:10 | Слайд «Проблема» | «Регламенты, инструкции и приказы занимают десятки страниц. Они написаны на разных языках, часть существует только как сканы. Обычные чат-боты придумывают ответы и не показывают, откуда их взяли. На производстве ошибка в инструкции по охране труда стоит дорого.» |
| 1:10–1:50 | Слайд «Как это работает» | «Мы используем технологию RAG. Документ разбирается на фрагменты с номерами страниц, сканы распознаются с помощью OCR. На вопрос система находит нужные фрагменты, а языковая модель отвечает только по ним и ставит ссылки на источники.» |
| 1:50–2:00 | Страница входа → «Войти» | «Каждый пользователь входит в свой аккаунт — документы видит только он. Для гостей есть быстрый вход.» |
| 2:00–2:40 | Сайт: загрузить `Innovation_AI_Hackathon_2026_Ereje.pdf` | «Загружаем регламент хакатона на казахском. Бот сразу показывает краткое содержание и подсказывает вопросы.» Спросить по-русски: **«Когда и где пройдёт финал?»** → «Ответ на русском, хотя документ на казахском. Нажимаем на ссылку [1] — видим точную цитату и страницу, можно открыть PDF прямо на этой странице.» |
| 2:40–3:10 | Нажать на источник 📍 под ответом | «Главное отличие от обычных чат-ботов: нажимаем на источник — открывается настоящая страница документа, и строки, на которых основан ответ, подсвечены маркером. Ответ можно проверить за секунду. Под ответом — индикатор доверия.» |
| 3:10–3:40 | Загрузить `Scan_AIChatBots_talaptary.pdf` | «Это скан — в нём нет текста, только картинка. Значок OCR: бот распознал страницу.» Спросить: **«Құжаттармен жұмыс сапасы неше балл?»** → 30 баллов. |
| 3:40–4:20 | Вкладка 🧭 **Құжат картасы**, документ — регламент | «Не обязательно задавать вопросы. Карта документа: AI сам нашёл все сроки, ключевые цифры и требования. Требования — это интерактивный чек-лист: отмечаем, что уже выполнено. Каждый пункт ведёт на свою страницу.» Отметить 2 пункта, нажать 📍 у одного. |
| 4:20–5:10 | Загрузить `Instrukciya_po_ohrane_truda.docx` → вкладка 🎓 **Білімді тексеру** → 5 вопросов | «Представим: рабочий прошёл инструктаж по охране труда. Бот составляет тест по инструкции, сразу проверяет ответы, объясняет ошибки со ссылкой на пункт инструкции и показывает итоговый балл.» Ответить на 2–3 вопроса, показать результат. |
| 5:10–5:30 | Чат: **«What number should I call in case of fire?»**, затем **«Какая погода завтра?»** | «Вопрос на английском — ответ из русского документа. А если ответа в документах нет — бот честно об этом говорит.» |
| 5:30–5:50 | Телефон: Telegram-бот; переключить ҚАЗ/РУС/ENG | «Тот же бот доступен в Telegram. Интерфейс на трёх языках, работает на телефоне, есть голосовой ввод.» |
| 5:50–6:20 | Слайд «Где применять» и «Что дальше» | «DocMind AI полезен на производстве, в колледжах, в госсекторе. Дальше мы планируем WhatsApp, семантический поиск и подключение к системам документооборота. Спасибо! Рахмет!» |

Советы:
* Разрешение записи — не ниже 1080p, крупный масштаб браузера (Cmd + «+»), чтобы текст читался.
* Перед записью прогоните сценарий 1–2 раза: первый ответ модели может быть медленнее.
* Загрузите видео на YouTube (доступ «по ссылке») и вставьте ссылку в форму регистрации.
