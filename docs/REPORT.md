# Mind AI — отчёт о проделанной работе

**Направление:** AIChatBots — «Innovation AI Hackathon – 2026» (п. 5.1.2 Ереже)
**Рабочая версия:** https://chatbotai-production-51ae.up.railway.app
**Код:** https://github.com/adiletpn/ChatBotAI

## 1. Что это

Mind AI — веб-платформа и Telegram-бот, которые отвечают на вопросы по загруженным документам.
Пользователь загружает PDF, DOCX, презентацию, таблицу, скан или фото документа и задаёт вопрос
на казахском, русском или английском. Ответ строится **только по содержимому документа**
и сопровождается ссылкой на источник: файл, страница и подсвеченная цитата.

## 2. Соответствие требованиям регламента

| Требование (п. 5.1.2) | Как выполнено |
|---|---|
| Работа с PDF, DOCX и другими документами | PDF, DOCX (с таблицами), PPTX, XLSX, CSV, TXT, HTML, DOC/RTF, JPG/PNG |
| Точные и понятные ответы по содержанию | Технология RAG: поиск нужных фрагментов + языковая модель с запретом выдумывать |
| Использование ИИ и NLP | Языковая модель, определение языка, стемминг для казахского и русского, поиск BM25, перевод запроса на 3 языка |
| Telegram, WhatsApp или веб | Веб-платформа и Telegram-бот |
| Рабочая версия | Развёрнута на Railway, автотест из 48 проверок |
| Презентация и видео 5–7 минут | Презентация и сценарий видео в папке `docs/` |
| ★ Указание источника | Каждый ответ со ссылками [1], [2]; клик открывает страницу PDF с подсветкой нужных строк |
| ★ Многоязычие | Вопросы и ответы на kk/ru/en, в том числе вопрос на одном языке к документу на другом |
| ★ Сканированные документы | Распознавание текста (Tesseract) с казахской, русской и английской моделями |

## 3. Чем Mind AI отличается от обычного чат-бота

1. **Доказательство на странице.** Ответ можно проверить за секунду: открывается настоящая страница документа, строки подсвечены маркером. Под каждым ответом — индикатор «подтверждено N источниками».
2. **Карта документа.** Без единого вопроса ИИ раскладывает документ на сроки, ключевые цифры, интерактивный чек-лист требований и термины, каждый пункт со ссылкой на страницу.
3. **Проверка знаний.** Тест по документу с вариантами ответа, объяснениями и итоговым баллом. Пример применения: работник прошёл инструктаж по охране труда, и бот проверил, что он его усвоил.
4. **Казахский язык.** Поиск учитывает казахскую морфологию, OCR читает казахские сканы, интерфейс полностью на трёх языках.

## 4. Платформа

- **Аккаунты:** регистрация по email с подтверждением 6-значным кодом, вход, сброс пароля по коду, гостевой вход.
- **Безопасность:**
  - пароли хранятся только как хэш PBKDF2 с солью, требования — 8+ символов, буквы и цифры;
  - Gmail-алиасы считаются одним адресом, одноразовые почты запрещены;
  - лимиты запросов по IP, блокировка после 5 неверных паролей;
  - каждый пользователь видит только свои документы.
- **Настройки:** профиль, 5 тем оформления (Светлая, Тёмная, Бумага, Полночь, Системная), 6 акцентных цветов, размер текста, ширина чата, язык интерфейса и ответов, стиль ответа (кратко / подробно), экспорт чата, удаление данных и аккаунта, раздел «О системе».
- **Дизайн:** собственный минималистичный стиль, рукописный логотип «mind», шрифты Geologica и Onest с поддержкой казахского, адаптивная мобильная версия.
- **Офлайн-режим:** если языковая модель недоступна, бот всё равно находит и показывает нужные фрагменты с источниками.

## 5. Технологии

Python, FastAPI, потоковые ответы (SSE) · языковая модель через OpenAI-совместимый API (xKiro, `qwen3.7-max`) ·
PyMuPDF, python-docx, python-pptx, openpyxl · Tesseract OCR (kaz/rus/eng) · BM25 со стеммингом ·
HTML/CSS/JS без сборки · aiogram 3 (Telegram) · Docker, Railway · почта через Gmail SMTP.

## 6. Проверка качества

- Автотест `tests/smoke_test.py`: 48 проверок. Он проверяет загрузку всех форматов, OCR скана, поиск, ответы, регистрацию, коды, сброс пароля, изоляцию пользователей и настройки. Тест проходит на Python 3.12 (как на сервере) и 3.14.
- Ручная проверка на реальной модели: ответы на трёх языках со ссылками, межъязыковые вопросы (русский вопрос → казахский документ), честный ответ «в документах этого нет» на посторонний вопрос.
